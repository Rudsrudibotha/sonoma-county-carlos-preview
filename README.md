# Sonoma County Carlos

Static one-page website for Sonoma County Carlos: handyman work, junk hauling and yard work in Santa Rosa, CA and across Sonoma County.

- `index.html`, `styles.css`, `script.js`
- `images/`: job photos and the flyer (licence plates blurred), plus the header mark and favicon cropped from the flyer
- `apple-touch-icon.png`, `og-image.jpg`: home-screen icon and social sharing image
- `SOURCES.txt`: image credits
